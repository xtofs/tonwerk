# some theory

## harmonies

the three basic harmonies in C major are:
(see below for the roman numerals )

```plain
I = C = C E G
IV = F = F A C
V7 = G7 = G B D F
```

## Scale

A scale is simply a collection of notes

the C major scale is: `C D E F G A B`

The names second, third, fourth, fifth, sixth, seventh, octave originally refer to scale positions.

For example from C:

```plain
C D E F G A B C
1 2 3 4 5 6 7 8
```

## Key

A key adds tonal hierarchy and harmonic function.

When we say a piece is "in C major", we mean:

- The notes primarily come from the C major scale.
- C is heard as the tonal center ("home").
- Chords and melodies create expectations that resolve to C.

for example:

```plain
C  -> feels like home
F  -> away from home
G7 -> wants to return home
C  -> home again
```

That feeling comes from the key, not merely from the scale.

## scale degrees

The Roman numerals identify chords relative to the tonic (the home chord) of the _key_:

In C major, the scale is:
C D E F G A B
1 2 3 4 5 6 7

the degrees describe a chord's function within a key, independent of the actual chord names.

```plain
I    = C E G = C major
ii   = D F A = D minor
iii  = E G B = E minor
IV   = F A C = F major
V    = G B D = G major
vi   = A C E = A minor
vii° = B D F = B diminished
```

- Uppercase numerals mean major chords: I IV V
- Lowercase numerals mean minor chords: ii iii vi
- The ° symbol indicates diminished chords: vii°

## semitone distances

The names second, third, fourth, fifth, sixth, seventh, octave originally refer to scale positions, not semitone counts.

for example `C -> G = fifth` because G is the 5th note name counting inclusively:

```plain
C(1) D(2) E(3) F(4) G(5)
```

| Interval       |       | # Semitones |
| -------------- | ----- | ----------- |
| Perfect unison | P1    | 0           |
| Minor second   | m2    | 1           |
| Major second   | M2    | 2           |
| Minor third    | m3    | 3           |
| Major third    | M3    | 4           |
| Perfect fourth | P4    | 5           |
| Tritone        | A4/d5 | 6           |
| Perfect fifth  | P5    | 7           |
| Minor sixth    | m6    | 8           |
| Major sixth    | M6    | 9           |
| Minor seventh  | m7    | 10          |
| Major seventh  | M7    | 11          |
| Perfect octave | P8    | 12          |

Why "perfect", "major" and "minor"?

Some interval numbers come in only one common size: `Unison Fourth Fifth Octave`

## Intervals used in common chords

Major triad:

```plain
C E G
 
Root -> E = M3 = 4 semitones
Root -> G = P5 = 7 semitones
```

Minor triad:

```plain
C Eb G
 
Root -> Eb = m3 = 3 semitones
Root -> G = P5 = 7 semitones
```

Dominant seventh:

```plain
G7 = G B D F
 
G -> B = M3 ( 4 semitones )
G -> D = P5 ( 7 semitones )
G -> F = m7 ( 10 semitones )
```
